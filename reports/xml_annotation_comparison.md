# Сравнение XML-аннотаций `patches_101` и `patches_105`

Проверены исходные Pascal VOC XML canonical fold `flod1`. Контрольные суммы показывают, что каждая из пяти копий одного файла в `flod1`--`flod5` идентична своей одноимённой версии: это свойство fold-пакета, а не новые независимые изображения.

| Файл | SHA-256 | Класс | Число объектов |
| --- | --- | --- | ---: |
| `patches_101.xml` | `052f875873e9fbbbdb823fc5f3975a462cf80209c61edd3704dbcf137003192d` | `patches` | 3 |
| `patches_105.xml` | `05eafff1fdc2aa894a359ede9c6552dfe535a5a75dba4d9f8b77eb8ae71aaaa0` | `patches` | 3 |

Разметка **не совпадает**. Порядок объектов и классы одинаковы, но все три bounding box отличаются:

| Объект | `patches_101` (`xmin`, `ymin`, `xmax`, `ymax`) | `patches_105` (`xmin`, `ymin`, `xmax`, `ymax`) |
| ---: | --- | --- |
| 1 | `(27, 1, 78, 92)` | `(29, 1, 76, 92)` |
| 2 | `(113, 1, 175, 59)` | `(116, 1, 174, 53)` |
| 3 | `(129, 79, 176, 200)` | `(130, 78, 173, 200)` |

Следовательно, это конфликтующие аннотации двух записей с разными идентификаторами. Координаты имеют положительную площадь и остаются в границах изображения 200×200. Исходные XML не менялись.

## Решение для производного YOLO-набора

Последующая проверка JPEG установила, что `patches_101.jpg` и `patches_105.jpg` имеют один SHA-256: `4d2de82731b86cdbc7a66f2a9bfb01074bb4cb65e47bccf06b66470d53857071`. Визуальное наложение обеих разметок на общие пиксели сохранено в `reports/figures/conflicting_duplicate_annotations.png`: оба варианта правдоподобно локализуют три дефекта, поэтому объективно выбрать более точную границу по имеющимся данным нельзя.

Для воспроизводимости применяется фиксированное правило: при одинаковых JPEG и конфликтующих XML сохранять лексикографически меньший идентификатор. Поэтому `patches_101` оставлен в Train, а `patches_105` исключён **только** из `data/processed`. Оба оригинальных JPG/XML сохранены в `data/raw`. Канонический аудит по-прежнему содержит 1 800 исходных записей; для обучения используются 1 799 изображений (Train/Validation/Test = 1223/216/360).
